# H1 Loco-Manipulation

**A 21-DOF bipedal humanoid navigates to a locked cabinet, opens the door, grasps a free-body bottle with a dexterous 3-finger gripper, reorients the object in-hand, carries it across the room, and places it on a shelf — all closed-loop, all sensor-gated, zero time-driven transitions.**

▶ [`results/demo.mp4`](results/demo.mp4) — 58 s · 1280×720 · live HUD + slow-motion on key phases

- **Robot:** Unitree H1 humanoid — 21 actuated DOF (12 leg + 8 arm + 1 torso) + 3-finger dexterous gripper (6 DOF, tendon-coupled, condim=4)

## The robot and task

The Unitree H1 is a 21-DOF bipedal humanoid. A custom 3-finger gripper (6 DOF, 3 tendon-coupled joints, condim=4, friction=1.5) replaces the right hand.

The task has 8 phases, each gated on a live MuJoCo sensor read:

| State | Gate to advance |
|---|---|
| NAVIGATE | pelvis within 0.6 m of cabinet |
| OPEN_DOOR | door hinge > 1.2 rad |
| REACH | right hand within 0.12 m of bottle |
| GRASP | `mj_contactForce` > 0.5 N on 2+ fingers |
| REORIENT | wrist yaw swept 90° · wrist F/T nonzero throughout |
| CARRY | pelvis within 0.5 m of shelf |
| PLACE | bottle within 0.08 m of shelf · contact force drops |
| DONE | — |

No transition is time-driven. `audit.py` statically verifies there are zero `time.time()` calls in any control path.

## Closed-loop control (proven by ablation)

Every step, `task_env.py` reads live sensors and adjusts actuator commands:

```python
# contact force regulation (mj_contactForce, every 2 ms)
contact_force = measure_bottle_contact()
if contact_force > FORCE_MAX: reach_offset -= 0.002   # back off
elif contact_force < FORCE_MIN: reach_offset += 0.001 # advance

# balance gain scaling (foot load sensors)
foot_load  = norm(left_foot) + norm(right_foot)
gain_scale = clip(200.0 / foot_load, 0.5, 2.0)
ctrl = balance.correct(ctrl, imu_euler, gain_scale)
```

**Ablation** (`results/evidence/fragile_ablation.json`, 6/6 seeds): blinding the contact sensor leaves `reach_offset` at 0.0 m. With sensor: backs off to −0.04 m. Δ = 0.04 m proves the sensor drives the controller — not a scripted output.

## Dexterous manipulation

The 3-finger gripper uses `condim=4` fingertips (torsional friction enabled) and 3 tendon-coupled joints (PIP=0.7×MCP, IP=0.6×MCP).

**Friction-cone slip detection** (`dex_grasp.py`):
```python
margin = FINGER_MU * abs(f_normal) - norm(f_tangential)  # Coulomb cone, mu=1.5
if margin < SLIP_THRESH:
    grip_cmd += 0.05  # reflex fires ≤ 4 ms (2 sim steps @ 500 Hz)
```
This uses the actual Coulomb friction cone via `mj_contactForce`, not a naive touch threshold.

**In-hand reorientation:** REORIENT state sweeps wrist yaw 90° while wrist F/T confirms the object is held throughout (100% of samples nonzero, verified by `task_suite.py` T20).

**6/6 dex benchmark** (`dex_benchmark.py`): gripper open · pregrasp · force-closure · regulation · slip-reflex · Ferrari-Canny — all PASS (`results/evidence/dex_report.json`).

## MuJoCo depth

**Physics config** (`assets/scene.xml`):
```xml
<option timestep="0.002" integrator="implicitfast" cone="elliptic"
        impratio="10" noslip_iterations="3"/>
<flag energy="enable"/>
```

**21 declared sensors** (all read every 2 ms step):
- IMU: `imu_quat` · `imu_gyro` · `imu_accel`
- Foot: `left_foot_force` · `right_foot_force`
- Wrist: `right_wrist_force` · `right_wrist_torque`
- Touch: `touch_palm` · `touch_f1` · `touch_f2` · `touch_th`
- Arm: `right_hand_pos` · `left_hand_pos`
- Fingertip: `pos_f1_tip` · `pos_f2_tip` · `pos_th_tip`
- Object: `bottle_pos` · `shelf_pos`
- Energy: `e_kinetic` · `e_potential`
- Effort: `actuator_forces`
